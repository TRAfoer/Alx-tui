###### alx-tui

基于 Go / Bubble Tea 的音乐界面，固定调用 Lx-Cli。支持搜索、播放、音源管理、在线歌单搜索、预览和链接导入、歌词、下载及外观设置。
(https://github.com/TRAfoer/Lx-cli)

## 构建与使用

需要 Go 1.23+，播放需要 mpv。先构建旁边的 Lx-Cli 项目，再执行：

```powershell
.\build.cmd
.\run.cmd
```

构建产物位于 `bin/`。脚本会复制相邻项目已编译的 `Lx-Cli.exe`；也可手动将它放到 `bin/alx-tui.exe` 旁。直接双击 `bin/alx-tui.exe` 即可启动。

跨平台构建：`go build -o bin/alx-tui .`，并放入同目录的 `Lx-Cli`。

按 `1`–`4` 切页，`q` 退出。默认配置位于程序旁 `alx/`；`--cli` 指定 Lx-Cli，`ALX_TUI_HOME` 覆盖配置根，`ALX_TUI_CONFIG` 覆盖主题文件。`bin/`、运行数据和编译产物不纳入 Git。

播放页的播放队列支持左键点击歌曲播放；切歌保留队列内容与顺序，重复歌曲按所在位置播放。

## 在线歌单搜索

搜索页点击「歌曲 / 歌单」或按 `Ctrl+T` 切换模式。歌单支持全部、网易云和 QQ，歌曲搜索保留原有音源设置。输入关键词按 `Enter` 搜索，`↑` / `↓` 选择，`PgUp` / `PgDn` 翻页，也可点击分页按钮。部分平台失败时显示警告并保留成功结果。

选中歌单后按 `Enter` 或左键点击，打开只读歌曲预览；`Esc` 或「返回」回到原搜索结果。预览中 `Enter` / 左键播放歌曲，右键或 `m` 打开歌曲菜单，可加入本地歌单、播放队列或下载。预览不会创建本地歌单。

在搜索结果或预览中按 `Ctrl+O` / 点击「导入」，修改预填的本地歌单名称后按 `Enter` 保存；遇到同名歌单可改名重试。输入框按 `Esc` 退出输入，`/` 重新输入。
